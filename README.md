# バイト出退勤管理・給与自動計算Webアプリ 要件定義書

---

## 🧩 概要

このシステムは、アルバイトの出退勤管理および給与自動計算を行うWebアプリである。  
アルバイトはスマートフォンから出退勤時間を入力・修正し、自分の給与を確認できる。  
管理者はPCまたはiPadから全バイトの勤怠データと給与情報を確認・管理できる。

---

## 🧑‍💻 ユーザー種別

| ユーザー種別          | 主な利用端末   | 主な機能                     |
| --------------------- | -------------- | ---------------------------- |
| アルバイト（5名程度） | スマートフォン | 出退勤登録、給与確認         |
| 管理者                | PC / iPad      | 給与計算、勤怠確認、時給設定 |

---

## 🧠 機能要件

### アルバイト側機能

1. **ログイン機能**
   - Supabase Auth を利用した認証（メール+パスワード）
   - ログイン後、出退勤画面・給与確認画面に遷移可能

2. **出退勤登録**
   - 出勤時刻・退勤時刻をプルダウン形式で選択可能
   - 「現在時刻を入力」ボタンを設置し、クリックすると自動で現在時刻を反映
   - 入力データは Supabase の `attendance` テーブルに保存
   - 同一日に複数回登録防止（制御あり）

3. **給与確認**
   - 月単位での給与を表示（自動計算結果を反映）
   - 勤務日数・合計勤務時間・交通費を含めて表示
   - 表示例：
     ```
     勤務時間：120時間
     通常給与：¥120,000
     深夜手当：¥5,000
     交通費：¥3,000
     合計：¥128,000
     ```

---

### 管理者側機能

1. **ログイン機能**
   - Supabase Auth を利用
   - 管理者権限フラグでアクセス制御

2. **アルバイト一覧表示**
   - 各アルバイトの勤務データ一覧を表示
   - 期間フィルタ（例：月単位、日付指定）

3. **給与自動計算**
   - 通常勤務・深夜勤務・残業・交通費を考慮して自動計算
   - 深夜時間帯：22:00〜5:00（25%増）
   - 残業時間帯：8時間を超えた勤務時間（25%増）
   - 交通費：手入力または固定値設定可能
   - 計算結果は給与テーブルに保存

4. **時給登録・編集**
   - 各アルバイトごとに時給を設定可能
   - Supabase `users` テーブル内に時給カラムを保持（例：`hourly_wage`）

## 🧮 給与計算ロジック（概要）

勤務時間 = 退勤時刻 - 出勤時刻

【勤務時間の区分け】

1. 通常時間：8時間以内かつ22:00〜5:00以外の勤務時間
2. 深夜時間：8時間以内かつ22:00〜5:00の勤務時間
3. 残業時間：8時間を超えた勤務時間（22:00〜5:00以外）
4. 深夜＆残業時間：8時間を超えたかつ22:00〜5:00の勤務時間

給与 =
(通常時間 × 時給) +
(深夜時間 × 時給 × 1.25) +
(残業時間 × 時給 × 1.25) +
(深夜＆残業時間 × 時給 × 1.5) +
交通費

## 🧭 画面構成（概要）

### アルバイト側

1. **ログイン画面**
2. **出退勤登録画面**
   - 出勤時刻プルダウン
   - 退勤時刻プルダウン
   - 「現在時刻入力」ボタン
   - 登録ボタン
3. **給与確認画面**
   - 月選択プルダウン
   - 給与サマリー表示

### 管理者側

1. **ログイン画面**
2. **勤怠一覧画面**
   - フィルタ（期間・ユーザー）
   - 編集・削除
3. **時給設定画面**
   - 各バイトの時給変更
4. **給与集計画面**
   - 自動計算・確認・エクスポート（CSV出力など）
